# UI

Skills for Lightning Web Component **design and UX** on the Salesforce platform. SLDS 2 tokens, theming, accessibility, motion, mobile, Experience Cloud, and a combined review rubric.

These complement implementation skills (`sf-lwc`, Apex, Jest). They do not replace them.

Agentforce **chat cards** (Custom Lightning Types) are under [custom-lightning-types](../custom-lightning-types/) — those are Agentforce UI, not record-page LWCs.

## Packs

| Pack | What it covers |
|------|----------------|
| [lwc](./lwc/) | 11 skills: design, styling, theming, UX, content, motion, page composition, Experience Cloud, mobile, dataviz, review |

## Install

```bash
curl -sSL https://raw.githubusercontent.com/sfdc-brendan/Unofficial-Skills/main/ui/install.sh | bash
```

